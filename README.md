# java-convenience-store-precourse

## ✔️ 프로젝트 개요
- 편의점 상품 목록을 출력한다.
  - 상품 목록에 프로모션 상품이 포함될 수 있다.
- 구매할 상품명과 수량을 입력받는다.
  - 개별 상품은 쉼표(`,`)로 구분한다.
  - 개별 상품은 대괄호(`[]`) 사이에 있어야 한다.
  - 구매할 상품명과 수량은 하이픈(`-`)으로 구분한다.
- 오늘 날짜가 프로모션 기간 내에 포함된 경우 할인을 적용한다.
  - 프로모션은 N개 구매 시 1개 무료 증정한다.
  - 프로모션은 동일 상품에 여러 프로모션이 적용되지 않는다.
- 프로모션 적용이 가능한 상품에 대해 고객이 해당 수량 보다 적게 가져온 경우, 그 수량만큼 추가로 가져오면 혜택을 받을 수 있음을 안내한다.
- 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 하는 경우, 일부 수량에 대해 정가로 결제하게 됨을 안내한다.
- 멤버십 할인 적용 여부를 안내한다.
  - 멤버십은 프로모션 미적용 금액의 30% 할인한다.
  - 멤버십 할인은 최대 8,000원이다.
- 구매한 상품에 대해 영수증을 출력한다.
  - 영수증에는 구매 상품 내역, 증정 상품 내역, 금액 정보가 출력된다.
    - 구매 상품 내역에는 구매한 상품명, 수량, 가격이 포함된다.
    - 증정 상품 내역에는 프로모션에 따라 무료로 제공된 증정 상품 목록이 포함된다.
    - 금액 정보에는 총구매액, 행사할인, 멤버십할인, 내실돈이 포함된다.
- 추가 구매 여부를 묻는 메시지를 출력한다.

## ✔️ 구현 기능 목록

### 편의점 상품 목록을 출력하는 기능
- [x] 편의점 인사말을 출력하는 기능을 만든다.
- [x] 편의점 상품 목록을 출력하는 기능을 만든다
- [x] 구매할 상품명과 수량을 요구하는 메시지를 출력하는 기능을 만든다.
  - [x] 메시지에는 입력 예시를 같이 출력하는 기능을 만든다.

### 상품 목록을 초기화하는 기능
- [x] products.md를 사용하여 편의점 상품 목록을 초기화하는 기능을 만든다.
- [x] promotions.md를 사용하여 프로모션 상품 목록을 초기화하는 기능을 만든다. 

### 구매할 상품명과 수량을 입력하는 기능
- [x] 구매할 상품명과 수량을 입력 받는 기능을 만든다.
  - [x] 빈 문자열이 입력되는지 검증한다.
  - [x] 개별 상품이 쉼표(`,`)로 구분되는지 검증한다.
  - [x] 개별 상품이 대괄호(`[]`) 사이에 있는지 검증한다.
  - [x] 상품명과 수량은 하이픈(`-`)으로 구분되는지 검증한다. 

### 구매할 상품명과 수량을 저장하는 기능
- [x] 입력된 상품명이 편의점에 보유하고 있는 상품명인지 검증한다.
- [x] 입력된 수량이 0보다 큰 수가 입력되었는지 검증한다.
- [x] 입력된 수량이 재고 수량 보다 작거나 같은 수량으로 입력되었는지 검증한다.

### 프로모션 할인 기능
- [x] 프로모션 상품에 해당하는지 검증한다.
- [x] 오늘 날짜가 프로모션 기간 내에 해당하는지 검증한다.
- [x] 프로모션 기간 중인 경우
  - [x] 프로모션 재고를 우선 차감하는 기능을 만든다.
  - [x] 프로모션 재고가 부족하면 일반 재고를 차감하는 기능을 만든다.
  - [x] 프로모션 재고가 없는 경우 프로모션을 제한하는 기능을 만든다.
- [ ] 프로모션 대상인 상품의 개수 보다 고객이 적게 가져온 경우
  - [ ] 고객에게 혜택을 받을 수 있음을 안내하는 메시지를 출력하는 기능을 만든다.
  - [ ] 추가 여부를 확인하는 Y 또는 N을 입력 받는다.
    - [ ] 빈 문자열이 입력되는지 검증한다.
    - [ ] Y 또는 N이 입력되는지 검증한다.
    - [ ] Y를 입력하면 해당 상품의 개수를 m개 추가하여 프로모션을 진행하는 기능을 만든다.
    - [ ] N을 입력하면 해당 상품를 정가로 구매하는 기능을 만든다.
- [ ] 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 하는 경우
  - [ ] 고객에게 일부 수량에 대해 정가로 결제하게 됨을 안내하는 메시지를 출력하는 기능을 만든다.
  - [ ] 구매 여부를 확인하는 Y 또는 N을 입력 받는다.
    - [ ] 빈 문자열이 입력되는지 검증한다.
    - [ ] Y 또는 N이 입력되는지 검증한다.
    - [ ] Y를 입력하면 일부 수량에 대해 정가로 결제하는 기능을 만든다.
    - [ ] N을 입력하면 일부 수량에 대해 구매하지 않는 기능을 만든다.

### 멤버십 할인 기능
- [ ] 멤버십 할인 여부를 안내하는 메시지를 출력하는 기능을 만든다.
- [ ] 멤버십 할인 여부를 확인하는 Y 또는 N을 입력 받는다.
  - [ ] 빈 문자열이 입력되는지 검증한다.
  - [ ] Y 또는 N이 입력되는지 검증한다.
- [x] 멤버십 할인은 프로모션 적용 후 남은 금액에 30% 할인을 적용하는 기능을 만든다.
- [x] 멤버십 할인의 최대 한도를 8,000원으로 설정하는 기능을 만든다.

### 편의점 재고 수량을 감소시키는 기능
- [x] 구매한 상품의 수량만큼 감소시키는 기능을 만든다.

### 영수증 출력하는 기능
- [x] 영수증 항목에는 구매 상품 내역, 증정 상품 내역, 금액 정보를 포함하여 출력하는 기능을 만든다.
  - [x] 구매 상품 내역에 상품명, 수량, 가격이 포함되어 있는지 확인한다.
  - [x] 증정 상품 내역에 프로모션에 따라 무료로 제공된 증정 상품의 목록을 확인한다.
  - [x] 금액 정보에 총구매액, 행사할인, 멤버십할인, 내실돈이 있는지 확인한다.
- [x] 영수증의 구성 요소를 정렬하는 기능을 만든다.

### 추가 구매 여부를 확인하는 기능
- [ ] 추가 구매 여부를 확인하기 위해 안내 문구를 출력하는 기능을 만든다.
- [ ] 추가 구매 여부를 확인하는 Y 또는 N을 입력 받는다.
  - [ ] 빈 문자열이 입력되는지 검증한다.
  - [ ] Y 또는 N이 입력되는지 검증한다.
  - [ ] Y를 입력하면 종료하는 기능을 만든다.
  - [ ] N을 입력하면 편의점 인사말과 상품 목록을 출력하는 기능을 만든다.

### 예외 메시지를 출력하는 기능
- [x] 사용자가 잘못된 값을 입력하면 IllegalArgumentException을 발생시킨다.
- [x] 예외가 발생하면 [ERROR]로 시작하는 에러 문구를 출력하고, 그 부분부터 입력을 다시 받는다.
